# doc-assistant

Interactive assistant that answers questions about a local docs folder, with filesystem MCP access.

Generated by agent-forge (spec v1, runtime: pimono). Do not hand-edit
`guardrails.py` — change the spec's `guardrails` section and regenerate.

## Run

```bash
./run.sh --dry-run   # print the pi argv
./run.sh             # run one sitting
```

Input for the model is passed as pi arguments after `--`, e.g.
`./run.sh -- @brief.md`.

## Pause

```bash
touch doc-assistant.stop    # pause (next run writes a paused receipt and exits)
rm doc-assistant.stop       # resume
```

## Receipts

Every run writes `receipts/doc-assistant-last.json`: verdict, actions, note, ts.

## MCP servers

See `mcp.json` — point your runtime's MCP config at it.
