# hn-ai-sitter

Daily sitter that checks the HN front page and summarizes AI posts.

Generated by agent-forge (spec v1, runtime: pimono). Do not hand-edit
`guardrails.py` — change the spec's `guardrails` section and regenerate.

## Run

```bash
./run.sh --dry-run   # print the pi argv
./run.sh             # run one sitting
```

Input for the model is passed as pi arguments after `--`, e.g.
`./run.sh -- @brief.md`.

## Pause

```bash
touch hn-ai-sitter.stop    # pause (next run writes a paused receipt and exits)
rm hn-ai-sitter.stop       # resume
```

## Receipts

Every run writes `receipts/last.json`: verdict, actions, note, ts.

## MCP servers

This agent declares no MCP servers.
